Your Calibration Guide (do this before the real run)
Step 1 — Install dependencies

cd malta-road-recovery
pip install -r requirements.txt
Step 2 — Add your clips
Drop your files into data/raw/video/. They must follow this exact naming:


regional_10am.mp4   regional_1pm.mp4   regional_5pm.mp4
valley_10am.mp4     valley_1pm.mp4     valley_5pm.mp4
Step 3 — Capture a calibration still frame

python -c "
import cv2, sys
cap = cv2.VideoCapture(sys.argv[1])
cap.set(cv2.CAP_PROP_POS_FRAMES, 300)
_, f = cap.read()
cv2.imwrite('calibration_still.jpg', f)
cap.release()
print('Saved calibration_still.jpg')
" data/raw/video/regional_10am.mp4
Step 4 — Measure pixels_per_metre
Open calibration_still.jpg in GIMP / Preview / Paint. Find a road feature you know the real-world size of (lane marking = 3 m, lane width = 3.5 m). Count the pixel distance between its two ends.


pixels_per_metre = pixel_distance / real_distance_metres
Open vision/config.py and update the two lines marked # <-- REPLACE:


# Line ~37
"regional": { "pixels_per_metre": 8.5,   # <-- REPLACE  e.g. 11.4
# Line ~44
"valley":   { "pixels_per_metre": 10.2,  # <-- REPLACE  e.g. 13.7
Step 5 — Set your ROI polygon
In the same still image, click the 4 corners that trace the road lanes. Note the (x, y) pixel of each corner. Update the block in vision/config.py around line 75:


ROI_POLYGONS = {
    "regional": [
        (430, 350),   # top-left  ← replace with your (x, y) clicks
        (1490, 350),  # top-right
        (1750, 980),  # bottom-right
        (170, 980),   # bottom-left
    ],
    ...
}
Tip: If you want to disable the ROI temporarily while testing, set ROI_POLYGONS = None.

Step 6 — Verify visually (gate + ROI preview)

cd malta-road-recovery
python vision/virtual_gates.py --frame calibration_still.jpg --segment regional
This saves calibration_still_annotated.jpg with the gate line and ROI polygon drawn on it. Check that they sit on the road. Adjust GATE_Y_RATIOS in config.py if the gate line is in the wrong place.

Step 7 — First live run (preview mode)

python main.py --preview
A window opens. Watch vehicles cross the green line. Press Q to stop early. Confirm detections look right. The gate fires, and you'll see console output like:


[gate]  t=  42.1s  ID=3    car          38.5 km/h  dir=downward
Step 8 — Full batch run

python main.py
Output files:


data/processed/yolo_output/regional_10am_frames.csv   ← per-frame (frame, id, class, speed_kph, entry_time)
data/processed/yolo_output/regional_10am.csv          ← 1-min summary bins
data/processed/calibration/regional_10am_metrics.csv  ← flow, density, class ratios for SUMO
Step 9 — Run tests (optional but recommended)

cd malta-road-recovery
python -m pytest tests/test_gates.py -v
